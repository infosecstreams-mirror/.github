# Contributing to InfosecStreams Mirror

First off, thank you for considering contributing to InfosecStreams Mirror!

## Branching Strategy
We use a standard `develop` branching strategy. 
1. **Never commit directly to `main`.** 
2. All new features, bug fixes, and updates should be branched off `develop`.
3. Open a Pull Request targeting the `develop` branch.
4. Once tested, `develop` will be periodically merged into `main` for release.

## Submitting Pull Requests
- Please ensure your PR description clearly describes the problem and solution.
- Link any relevant issues using "Fixes #123".
